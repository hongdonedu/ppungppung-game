# 💨 뿡뿡! 방귀 피하기

> 방귀쟁이 몬스터들의 뿡뿡 공격을 요리조리 피하는 **1~2인용 · 30라운드** 웹 게임
> 부산 명진초등학교 최일훈 · 바이브코딩(2026)

설치 없이 브라우저에서 바로 실행됩니다(PC·태블릿·휴대폰).

## 바로가기
- 🎮 게임: https://hongdonedu.github.io/ppungppung-game/

## 놀이 방법
| 모드 | 조작 |
|---|---|
| 👤 1인용 | ← → 방향키 또는 A D 키, 손가락 드래그 |
| 👥 2인용 | 1P(왼쪽 자리) **A D** · 2P(오른쪽 자리) **← →** · 태블릿은 각자 손가락으로 |

- 몬스터 머리 위에 **!** 가 뜨면 곧 방귀! 색깔로 어떤 방귀인지 알 수 있어요.
- 시작 하트 4개 → 10라운드부터 5개 → 20라운드부터 6개
- 보스: 10라운드 **대왕 뿡뿡몬**, 20라운드 **방귀 대마왕**, 30라운드 **뿡뿡제왕**
- 도움 아이템: 🌈 무지개(하트 회복·친구 부활) · ✨ 황금(+100) · 🛡️ 비눗방울 방패 · ⏰ 시계(슬로우) · 🍀 클로버(점수 ×2)
- 기록은 이 기기의 브라우저에 저장되고 🏆 명예의 전당에서 볼 수 있어요.

| 10 | 👑 중간 보스 대왕 뿡뿡몬 |

| 20 | 😈 방귀 대마왕 |

## 그림은 이렇게 만들었어요
모든 그림은 **ChatGPT 이미지 생성**으로 한 대화방 안에서 이어서 만들었습니다(같은 화풍 유지).
1. 키아트를 먼저 그려 스타일과 캐릭터 생김새를 정함
2. "같은 스타일·같은 생김새로" 캐릭터 시트(표정 4종), 몬스터 시트(기본·방귀 참기·시원함), 보스, 방귀 구름 16종, 아이템을 요청
3. 시트는 **단색 크로마키 배경**(초록 #00FF00 · 파랑 #0000FF · 마젠타 #FF00FF)으로 요청 → 배경을 지우고 한 장씩 잘라 사용
   - 초록 몬스터·초록 방귀가 있는 시트는 초록 배경을 쓰면 같이 지워지므로 파랑·마젠타 배경을 골랐어요
